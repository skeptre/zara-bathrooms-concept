# Zara Bathrooms — independent website concept

A responsive, static website concept by Virezio for a possible Zara Bathrooms online showroom. It is **not** the official Zara Bathrooms website and is not affiliated with or endorsed by the business.

## Preview

Serve this directory with any static HTTP server, such as `python3 -m http.server 4173`, then open `http://localhost:4173`.

## Before official use

- Replace illustrative photography with licensed, approved showroom and project images.
- Confirm the current business address, phone, services, opening hours, and review figures with Zara Bathrooms.
- Connect the enquiry form to a real, consent-aware delivery service. The current form only prepares text for copying and sends nothing.
- Remove concept notices and `noindex` only with the business's approval and after a production launch plan.
